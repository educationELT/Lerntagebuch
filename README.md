# 📘 Progress Planner

Ein digitales Lerntagebuch für den Unterricht – zum Planen, Arbeiten und Reflektieren.

**Zur App:** https://educationelt.github.io/lerntagebuch/

## Funktionen
- Arbeitsort und Lernpartner/in festhalten (inkl. Ampelsystem)
- Check-in zu Beginn der Stunde, Aufgaben und Notizen
- Exit ticket mit verschiedenen Reflexionsformen
- Lernkalender und Lernverlauf
- Münzen und Emojis als Motivation
- Wörterbuch-Suche (dict.cc)
- Zusammenfassung kopieren oder als PDF speichern

## Datenschutz
- Keine Anmeldung, kein Konto nötig
- Alle Eingaben werden **nur lokal auf dem eigenen Gerät** gespeichert
- Es werden keine Daten an einen Server übertragen oder hier gespeichert
- Wird der Browserverlauf gelöscht, sind auch die Einträge weg – deshalb regelmäßig als PDF sichern
